4. Accedi all'applicazione tramite l'Ingress: http://{{ .Values.Ingress.host }}

   Stai usando minikube con il driver docker (colima), quindi il cluster gira dentro
   una VM/container e l'IP del nodo non è raggiungibile direttamente dal Mac. Servono
   due passaggi una tantum:

   a) Mappa l'host "{{ .Values.Ingress.host }}" su localhost nel file /etc/hosts del Mac:

      echo "127.0.0.1 {{ .Values.Ingress.host }}" > /etc/hosts

   b) Esponi l'Ingress Controller sulla porta 80 del Mac con un port-forward
      (lascia il terminale aperto; la porta 80 richiede sudo):

      sudo kubectl --namespace {{ .Release.Namespace }} \
        port-forward svc/{{ .Release.Name }}-ingress-nginx-controller 80:80

   Poi visita:  http://{{ .Values.Ingress.host }}

   In alternativa, se imposti il Service del controller come LoadBalancer, puoi tenere
   attivo un tunnel persistente con:  minikube tunnel   (e saltare il port-forward).
